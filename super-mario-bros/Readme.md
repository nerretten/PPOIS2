# Лабораторная работа 3

## Описание проекта
В данной лабораторной работе реализован прототип 2D-платформера, вдохновленный классической игрой Super Mario Bros. Проект демонстрирует применение принципов объектно-ориентированного программирования, работу с игровым циклом, реализацию базового физического движка и обработку столкновений.

## Архитектура проекта
Для предотвращения циклических зависимостей и повышения читаемости, монолитный код был разделен на 6 логических модулей:

* **`settings.py`** — Базовый уровень конфигурации. Отвечает за инициализацию Pygame, настройку окна, загрузку физических параметров и чтение JSON-файлов (`config.json`, `level.json`).
* **`assets.py`** — Менеджер ресурсов. Загружает и масштабирует спрайты, шрифты, звуковые эффекты и фоновую музыку.
* **`entities.py`** — Игровые сущности. Содержит классы объектов (`Entity`, `Player`, `Enemy`, `Block`, `FloatingText`), описывающие их поведение, физику и логику взаимодействия.
* **`game.py`** — Логика уровня. Реализует паттерн "Игровой цикл" (обработка событий, обновление состояний, рендеринг), управление камерой (скроллинг экрана) и систему очередей событий (Spawn Queue).
* **`ui.py`** — Пользовательский интерфейс. Отвечает за отрисовку текста, экранов победы/поражения и логику сохранения/чтения таблицы рекордов из `highscores.json`.
* **`main.py`** — Точка входа приложения. Управляет главным меню, навигацией по разделам (Старт, Рекорды, Помощь) и запуском игрового цикла.

## Основные игровые механики

### 1. Физическая модель
Перемещение главного героя (`Player`) реализовано с учетом инерции, трения и гравитации. 
Ускорение применяется при нажатии клавиш управления, а при их отпускании скорость плавно гасится силой трения. Максимальная скорость программно ограничена.

### 2. Обработка коллизий 
Проверка столкновений разделена на две фазы:
1.  **По оси X:** Вычисляется сдвиг по горизонтали. При столкновении со стеной скорость обнуляется, а координаты игрока выравниваются по границе препятствия.
2.  **По оси Y:** Вычисляется сдвиг под действием гравитации. При столкновении с полом игрок останавливается, а флаг `on_ground` переводится в `True`, разрешая новый прыжок.

### 3. Взаимодействие с блоками 
При ударе игроком о блок снизу (`on_hit`), блок получает вертикальный импульс (`vel_y = -5`). В игровом цикле каждый кадр блок обновляет свою позицию, подвергаясь воздействию гравитации, пока не вернется на свою исходную координату (`base_y`). Если блок содержит монету или врага, происходит генерация соответствующего события через `spawn_queue`.

### 4. Взаимодействие с врагами
Уничтожение врагов (`Enemy`) рассчитывается на основе вектора скорости и относительных координат. Если игрок двигается вниз (`vel_y > 0`) и его нижняя граница (hitbox) находится выше центра врага, засчитывается успешная атака: враг уничтожается, а игрок получает импульс для отскока. В противном случае игрок получает урон.

## Управление
* **A, D / Стрелки Влево-Вправо** — Перемещение по горизонтали.
* **W / Пробел / Стрелка Вверх** — Прыжок.
* **ESC** — Выход в главное меню / Возврат на предыдущий экран.

## Требования для запуска
* Python 3.x
* Pygame (`pip install pygame`)
* Наличие папки `assets/` с ресурсами и конфигурационных файлов `config.json`, `level.json` в корневой директории проекта.

## Запуск проекта
Точкой входа является файл `main.py`. Для запуска игры выполните команду:
`python main.py`
